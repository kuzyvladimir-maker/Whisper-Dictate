# Whisper Dictate Lite (MacBook)

Диктовка для любого Mac, включая Intel, по образцу Wispr Flow. Держите клавишу и говорите. Когда отпустите, в активное поле вставится готовый текст: с пунктуацией, абзацами и без слов-паразитов. Распознавание и причёсывание делает Gemini Flash Lite; два ключа соревнуются за первый ответ. Без сети или при исчерпанном лимите можно включить локальный whisper.cpp.

iMac-версия (корень репозитория) не меняется. Это отдельное приложение со своим bundle id (`com.whisperdictate.lite`), обе версии могут стоять на одном Mac.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/kuzyvladimir-maker/Whisper-Dictate/main/macbook/install.sh | bash
```

Из клона репозитория то же самое делает `bash macbook/install.sh`. Если добавить `--with-local`, установщик ещё поставит локальный фолбэк: whisper.cpp и модель small, около 470 МБ.

Нужны macOS 11+ и Xcode Command Line Tools. Если их нет, установщик сам откроет окно установки, после него команду нужно запустить ещё раз. Приложение собирается из исходников прямо на машине, поэтому собранный бинарник подходит к её процессору и версии macOS. Именно это сломало x86-сборку iMac-версии: там бинарники были собраны с minos 26.0.

## Первый запуск

1. **Универсальный доступ.** macOS спросит сама: Открыть Системные настройки → включить *Whisper Dictate Lite*. Без этого не работают горячая клавиша и вставка.
2. **Микрофон.** Нажмите «Разрешить».
3. **Ключ Gemini.** Впишите ключ в файл `~/.config/whisper-dictate/env`:
   ```
   GEMINI_API_KEY=ключ1,ключ2,ключ3
   ```
   Файл создаётся с правами 600. Ключ не коммитить и не пересылать в чатах. Несколько бесплатных ключей пишутся через запятую. Потом откройте меню значка → «Перечитать ключи и словарь».

По умолчанию приложение подписывается ad-hoc, и при каждом обновлении подпись меняется — галочку «Универсальный доступ» (и доступ к микрофону) приходится включать заново; установщик сам сбрасывает старую запись, чтобы macOS спросила снова. Чтобы разрешения переживали обновления, один раз создайте устойчивую self-signed подпись (в обычной сессии, не по SSH — шаг с ключом может потребовать пароль входа):
```
bash macbook/make-signing-identity.sh
```
Если identity доступна для подписи, `build.sh` использует постоянный сертификат «Whisper Dictate Lite Self-Signed». `install.sh` проверяет фактическую подпись установленного приложения и не сбрасывает TCC для подписи сертификатом (включая `WDL_SIGN_IDENTITY`). Сохранение разрешений надо проверить двумя обновлениями на целевом Mac; здесь оно не подтверждено. Без доступной identity остаётся ad-hoc и прежний сброс разрешений. Скрипт не запрашивает пароль входа и не меняет доступ ко всем ключам связки.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Держать **Fn** (🌐) | идёт запись, после отпускания текст вставится |
| Коротко нажать | запись идёт до следующего нажатия |
| **Esc** | отменить запись или прервать долгий запрос (запись сохранена на диске для повтора) |
| Fn + другая клавиша (стрелки, Delete, F1…) | обычное действие клавиши, запись отменяется |

Fn выбрана по умолчанию: та же клавиша, что на iMac, и та же, что в Wispr Flow. Установщик выставляет «Нажатие клавиши fn/🌐: Ничего не делать» (`AppleFnUsageType=0`), иначе Fn при отпускании ещё переключала бы раскладку или открывала эмодзи. Вернуть можно в Системных настройках → Клавиатура.

В меню есть ещё правый ⌘ и правый ⌥. С правым ⌥ мешает **Punto Switcher**: у него на одиночный Option назначено действие, и на каждое отпускание он шлёт Cmd+C (на iMac это видно в журнале). Диктовку это не ломает, синтетические нажатия чужих программ приложение игнорирует. Но Punto при этом может переключить раскладку выделенного текста.

Если во время записи микрофон молчит (6 с до начала речи или 20 с в паузе), поверх окон появляется красная панель «Тебя не слышно — говори громче (запись идёт)», как на iMac. Микрофон остаётся открытым 30 с после диктовки, поэтому следующая начинается без повторного открытия CoreAudio.

Для защиты краёв фразы (задержка Bluetooth как причина потери окончания пока не подтверждена): при отпускании клавиши запись продолжается ещё `tail_seconds` (по умолчанию 0.4 с) — успевает попасть окончание; Esc всё равно отменяет сразу. А пока микрофон открыт, приложение держит кольцевой буфер последних `pre_roll_seconds` (0.6 с) и подклеивает его к началу следующей записи — не теряется начало между нажатием клавиши и стартом захвата. После холодного открытия микрофона pre-roll ещё нет: буфер не может восстановить звук, который устройство не передало. При смене устройства (подключились AirPods) микрофон переоткрывается, уже записанные сэмплы сохраняются; звук во время самого переоткрытия может быть потерян.

Значок в строке меню: 🎙 значит «готов», красный микрофон с таймером — «идёт запись», ⋯ — «распознаю», ⚠️ — «нужно разрешение или ключ». Есть звуки старта и конца записи (Ping/Pop, как на iMac), их можно выключить в меню.

**Режимы** (переключаются в меню):
- **Обычный.** Дословно, с пунктуацией и абзацами, без паразитов.
- **Письмо.** Обращение и подпись отдельными строками, короткие абзацы. Разговорная грамматика выравнивается до письменной, новые факты не добавляются.
- **Код / промпт для ИИ.** Точное написание терминов (camelCase, пути, команды в `обратных кавычках`), шаги нумерованным списком. Задача только записывается, модель её не решает.

**Словарь — общий с iMac-версией.** Один файл `iCloud Drive/WhisperDictate/dictionary.txt` синхронизируется между Маками и в публичный репозиторий не попадает. Формат как на iMac:
```
вику | вико = Veeqo
Salutem
```
Первая строка: «как может прозвучать = как писать», то есть и замена, и подсказка для Gemini. Вторая: только подсказка написания. Комментарии допускаются лишь отдельной строкой, начинающейся с `#`.
Слова из словаря подмешиваются в промпт Gemini, а замены применяются к готовому тексту. Словари для отдельных приложений лежат рядом, в `dictionaries/<bundle id>.txt`; в меню есть пункт «Словарь для «Приложение»…». Пункт «Добавить слово из буфера» дописывает скопированное слово или строку `услышал = Как писать`. Если файл в iCloud выгружен или ещё не скачан, работает локальная копия `~/.config/whisper-dictate/dictionary.cache.txt`. Правки подхватываются при следующей диктовке.

**Только локально (без Google).** Переключатель в меню. Аудио не покидает Mac, распознаёт whisper.cpp small, текст без причёсывания. Требует установки с `--with-local`.

## Приватность

- В режиме Gemini аудио уходит запросом в Google. Локальному whisper.cpp нужен файл: временный WAV с правами 600 удаляется сразу после распознавания.
- Последние записи (по умолчанию 20) сохраняются на диск в `~/Library/Application Support/WhisperDictateLite/recordings/` (WAV, права 600, вне репозитория и вне iCloud), чтобы перезапуск или сбой не потеряли надиктованное. Старые удаляются автоматически. «Повторить отправку последней записи» берёт свежайшую с диска; пункт меню «Папка записей…» открывает папку. Чтобы записи не хранились, поставьте `recordings_kept: 0`.
- В журнале `~/Library/Logs/WhisperDictateLite.log` пишутся только тайминги и ошибки, без текста и аудио. Ключ в журнал не попадает, только его номер (#1, #2).

## Модели, ожидание и лимиты

Цепочка моделей: `gemini-3.5-flash-lite` → `gemini-3-flash-preview` → `gemini-3.1-flash-lite` → `gemini-3.6-flash`. Модели «другого пула» задаются в `fallback_models`. Режим меняет только промпт.

**Как ждём ответ.** Замер 18.11 на одних и тех же записях показал две особенности Gemini. Задержка двухрежимная: около 1.5 с или около 7 с, независимо для каждого запроса. Кроме того, примерно треть запросов вообще не получала ответа и висела до тайм-аута. Поэтому:
- сразу уходят два запроса на flash-lite с разными ключами (два шанса на быстрый ответ);
- если за 2.5 с ответа нет (плюс 0.03 с на секунду аудио), уходит третий запрос на другую модель и третий ключ;
- побеждает первый ответ, остальные отменяются. 3.6-flash (20 запросов в сутки) для дублей не используется;
- **общий дедлайн** одной диктовки — 12 с + 0.25 с на секунду аудио, не больше 30 с. После него показывается ошибка, а запись остаётся на диске для «Повторить отправку» (она сохраняется до запроса). Раньше висящий запрос ждал до 15.7 с и повторялся последовательно, поэтому отказы случались через 47–58 с.

**Ошибки ключей.** На 402 «prepayment credits are depleted» ключ отключается на 6 ч, и запрос сразу идёт на следующий. Раньше 402 был фатальным, а перебор ключей стоял на этом ключе: 17.11 так провалились 21 диктовка подряд. На 429 пара «модель + ключ» ждёт `retryDelay` (при суточном лимите — час). Модель с ответом 404 пропускается. Gemini 2.x в настройках игнорируется.

В журнал по каждому запросу пишется `gemini timing … upload … wait … download`, то есть отдельно загрузка, ожидание сервера и скачивание. По каждой диктовке пишутся `audio=`, `release->paste=`, модель-победитель и число запросов.

## Настройки

Файл `~/.config/whisper-dictate/lite.json` создаётся при первом изменении в меню.

| Ключ | По умолчанию | |
|---|---|---|
| `fast_model` | `gemini-3.5-flash-lite` | основная модель во всех режимах |
| `model` | `gemini-3.6-flash` | запасная модель во всех режимах |
| `long_audio_seconds` | `20` | сохранено для совместимости; маршрутизация теперь одинакова для всех длин |
| `fallback_models` | `[]` | дополнительные запасные модели в конце цепочки |
| `hold_threshold_seconds` | `0.35` | граница между «держу» и «короткое нажатие» |
| `tail_seconds` | `0.4` | сколько писать после отпускания клавиши (чтобы не срезать окончание) |
| `pre_roll_seconds` | `0.6` | буфер перед нажатием, подклеиваемый к началу записи |
| `recordings_kept` | `20` | сколько последних записей хранить на диске (0 — не хранить) |
| `max_recording_seconds` | `600` | автостоп записи |
| `restore_clipboard`, `restore_delay_seconds` | `true`, `0.8` | вернуть прежний буфер обмена |
| `append_space` | `true` | пробел после вставки (кроме режима «код») |
| `paste` | `true` | `false` — только копировать в буфер, без Cmd+V |
| `mic_idle_close_seconds` | `30` | сколько секунд микрофон остаётся открытым после диктовки |
| `hearing_alert` | `true` | панель «Тебя не слышно» во время записи |
| `local_fallback` | `true` | whisper.cpp, если Gemini недоступен |
| `language` | `ru` | язык для whisper.cpp |
| `whisper_cli`, `whisper_model` | авто | пути, если whisper.cpp стоит не там, где его ищет приложение |

## Проверка и замер

```bash
APP="$HOME/Applications/Whisper Dictate Lite.app/Contents/MacOS/WhisperDictateLite"
"$APP" --selftest                       # офлайн-проверки, ключи, whisper.cpp, разрешения
"$APP" --list-models                    # какие Flash-модели доступны ключу
"$APP" --bench запись1.wav запись2.m4a  # задержка «отпустил → текст» на своих записях
"$APP" --bench --model gemini-3.5-flash-lite --mode email запись.wav
```

`--bench` запускает тот же код, что и приложение: прогрев соединения на старте записи, затем WAV и запрос. В меню видна задержка последней диктовки («Последняя: 1.4 с после отпускания…»).

## Удаление

`bash macbook/uninstall.sh` удаляет приложение, а с `--purge` ещё ключи, словарь и локальную модель.

## Почему Swift, а не Python

Один нативный бинарник примерно на 1 МБ без зависимостей. Нет Python, numpy и PortAudio, у которых x86-сборки привязаны к версии macOS. Всё нужное есть в системе: AVAudioEngine для записи в память, URLSession с HTTP/2 для Gemini, CGEventTap для горячей клавиши и вставки, NSStatusItem для меню. Сборка занимает около 20 секунд на самой машине, поэтому код всегда совпадает с её архитектурой.

## Приёмка на MacBook после обновления

- На встроенном микрофоне и AirPods продиктовать фразы с различимыми первым и последним словами: после простоя >30 с, затем повторно в течение 30 с. В журнале проверить `tail 0.40s`, на тёплом старте — pre-roll до 0.60 с. Прослушать сохранённый WAV и сравнить с текстом.
- Переключить устройство во время фразы: начало до переключения должно остаться в WAV. Отдельно проверить Esc в течение хвоста: отменённая запись не отправляется.
- Отключить сеть, завершить диктовку, перезапустить приложение и выбрать повтор последней записи после восстановления сети. Повтор не создаёт новую копию в архиве; лимит 20 относится к завершённым записям. Esc во время самой записи её отбрасывает.
- Проверить `stat -f '%Lp'` для WAV (600) и папки (700). При ошибке записи на диск приложение сообщает об этом и сохраняет временную копию в памяти.
- Проверить обновление с одной и той же signing identity: `codesign -dr -` до/после, затем Fn, вставку и микрофон без повторной выдачи разрешений. Это аппаратная приёмка, `--selftest` её не заменяет.

Офлайн `--selftest` дополнительно проверяет гонку двух подставных ключей без обращения к Google, отмену проигравшего запроса, 429, права архива, ротацию и чтение WAV после повторного открытия. Реальную скорость API он не измеряет.
