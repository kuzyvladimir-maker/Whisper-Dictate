# Whisper Dictate Lite (MacBook)

Диктовка для любого Mac, включая Intel, по образцу Wispr Flow. Держите клавишу и говорите. Когда отпустите, в активное поле вставится готовый текст: с пунктуацией, абзацами и без слов-паразитов. Распознавание и причёсывание делает Gemini Flash за один запрос. Без сети или при исчерпанном лимите можно включить локальный whisper.cpp.

iMac-версия (корень репозитория) не меняется. Это отдельное приложение со своим bundle id (`com.whisperdictate.lite`), обе версии могут стоять на одном Mac.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/kuzyvladimir-maker/Whisper-Dictate/main/macbook/install.sh | bash
```

Из клона репозитория то же самое делает `bash macbook/install.sh`. Если добавить `--with-local`, установщик ещё поставит локальный фолбэк: whisper.cpp и модель small, около 470 МБ.

Нужны macOS 11+ и Xcode Command Line Tools. Если их нет, установщик сам откроет окно установки, после него команду нужно запустить ещё раз. Приложение собирается из исходников прямо на машине, поэтому собранный бинарник подходит к её процессору и версии macOS. Именно это сломало x86-сборку iMac-версии: там бинарники были собраны с minos 26.0.

## Первый запуск

1. **Универсальный доступ.** macOS спросит сама: Открыть Системные настройки → включить *Whisper Dictate Lite*. Без этого не работают горячая клавиша и вставка.
2. **Микрофон.** Нажмите «Разрешить».
3. **Ключ Gemini.** Впишите ключ в файл `~/.config/whisper-dictate/env`:
   ```
   GEMINI_API_KEY=ключ1,ключ2,ключ3
   ```
   Файл создаётся с правами 600. Ключ не коммитить и не пересылать в чатах. Несколько бесплатных ключей пишутся через запятую. Потом откройте меню значка → «Перечитать ключи и словарь».

После переустановки или обновления подпись приложения меняется, и галочку «Универсальный доступ» придётся включить заново. Установщик сам сбрасывает старую запись, чтобы macOS спросила снова.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Держать **правый ⌥ Option** | идёт запись, после отпускания текст вставится |
| Коротко нажать | запись идёт до следующего нажатия |
| **Esc** | отменить запись или прервать долгий запрос (запись останется в памяти для повтора) |
| Option + другая клавиша | обычный ввод символа, запись отменяется |

Клавишу можно сменить в меню: правый ⌥, Fn/🌐 или правый ⌘. Если выбрать Fn, в Системных настройках → Клавиатура нужно выставить «Нажатие клавиши fn/🌐: Ничего не делать», иначе Fn будет ещё и переключать раскладку.

Значок в строке меню: 🎙 значит «готов», красный микрофон с таймером — «идёт запись», ⋯ — «распознаю», ⚠️ — «нужно разрешение или ключ». Есть звуки старта и конца записи (Ping/Pop, как на iMac), их можно выключить в меню.

**Режимы** (переключаются в меню):
- **Обычный.** Дословно, с пунктуацией и абзацами, без паразитов.
- **Письмо.** Обращение и подпись отдельными строками, короткие абзацы. Разговорная грамматика выравнивается до письменной, новые факты не добавляются.
- **Код / промпт для ИИ.** Точное написание терминов (camelCase, пути, команды в `обратных кавычках`), шаги нумерованным списком. Задача только записывается, модель её не решает.

**Словарь.** Бренды и имена лежат в `~/.config/whisper-dictate/dictionary.txt`, по одному в строке. Можно подсказать звучание, например `Veeqo = вику`. Словарь подмешивается в промпт. После правки: меню → «Перечитать ключи и словарь».

**Только локально (без Google).** Переключатель в меню. Аудио не покидает Mac, распознаёт whisper.cpp small, текст без причёсывания. Требует установки с `--with-local`.

## Приватность

- Аудио пишется только в оперативную память и никуда не сохраняется. В режиме Gemini оно уходит одним запросом в Google. Локальному whisper.cpp нужен файл: временный WAV с правами 600 удаляется сразу после распознавания.
- Если запрос не удался, последняя запись хранится только в памяти для пункта «Повторить отправку» и пропадает после следующей успешной диктовки или выхода из приложения.
- В журнале `~/Library/Logs/WhisperDictateLite.log` пишутся только тайминги и ошибки, без текста и аудио. Ключ в журнал не попадает, только его номер (#1, #2).

## Лимиты бесплатных ключей

На ответ 429 приложение помечает пару «модель + ключ» на время из `retryDelay` (при суточном лимите — на час) и сразу пробует следующий ключ. Когда кончились все ключи, оно переходит на запасную модель: у неё отдельная квота. Если какая-то пара освободится в течение 8 секунд, приложение один раз подождёт. Ключи используются по кругу, поэтому лимит в минуту делится между ними. Когда не помогло ничего, включается локальный whisper.cpp (если установлен). Иначе выдаётся ошибка, а запись можно отправить повторно из меню.

## Настройки

Файл `~/.config/whisper-dictate/lite.json` создаётся при первом изменении в меню.

| Ключ | По умолчанию | |
|---|---|---|
| `model` | `gemini-2.5-flash` | основная модель |
| `fallback_models` | `["gemini-2.5-flash-lite"]` | запасные модели при 429 или 5xx |
| `hold_threshold_seconds` | `0.35` | граница между «держу» и «короткое нажатие» |
| `max_recording_seconds` | `600` | автостоп записи |
| `restore_clipboard`, `restore_delay_seconds` | `true`, `0.8` | вернуть прежний буфер обмена |
| `append_space` | `true` | пробел после вставки (кроме режима «код») |
| `local_fallback` | `true` | whisper.cpp, если Gemini недоступен |
| `language` | `ru` | язык для whisper.cpp |
| `whisper_cli`, `whisper_model` | авто | пути, если whisper.cpp стоит не там, где его ищет приложение |

## Проверка и замер

```bash
APP="$HOME/Applications/Whisper Dictate Lite.app/Contents/MacOS/WhisperDictateLite"
"$APP" --selftest                       # офлайн-проверки, ключи, whisper.cpp, разрешения
"$APP" --list-models                    # какие Flash-модели доступны ключу
"$APP" --bench запись1.wav запись2.m4a  # задержка «отпустил → текст» на своих записях
"$APP" --bench --model gemini-2.5-flash-lite --mode email запись.wav
```

`--bench` запускает тот же код, что и приложение: прогрев соединения на старте записи, затем WAV и запрос. В меню видна задержка последней диктовки («Последняя: 1.4 с после отпускания…»).

## Удаление

`bash macbook/uninstall.sh` удаляет приложение, а с `--purge` ещё ключи, словарь и локальную модель.

## Почему Swift, а не Python

Один нативный бинарник примерно на 1 МБ без зависимостей. Нет Python, numpy и PortAudio, у которых x86-сборки привязаны к версии macOS. Всё нужное есть в системе: AVAudioEngine для записи в память, URLSession с HTTP/2 для Gemini, CGEventTap для горячей клавиши и вставки, NSStatusItem для меню. Сборка занимает около 20 секунд на самой машине, поэтому код всегда совпадает с её архитектурой.
