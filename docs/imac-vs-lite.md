# iMac-версия и Whisper Dictate Lite: сравнение и план объединения

Состояние на 10.11.2026. Сравнивался код двух версий:
- **iMac-версия:** корень репозитория, коммит 658fe34 (`main.py`, `recorder.py`, `transcriber.py`, `whisper_server.py`, `live_chunker.py`, `cleaner.py`, `vocabulary.py`).
- **Lite:** папка `macbook/`, коммит c832912.

Цифры задержки iMac взяты из её рабочего журнала (последние 400 диктовок). Цифры Lite — из замера Джеки на MacBook.

## Сравнение по возможностям

| | iMac-версия | Lite (`macbook/`) |
|---|---|---|
| **Платформа** | На деле только Apple Silicon: Metal включён только для arm64. x86-сборка не стартует, потому что whisper-cli собран с minos 26.0, а numpy требует macOS 14+ | Intel и Apple Silicon, macOS 11+. Собирается из исходников прямо на машине |
| **Стек** | Python 3.11 (rumps, pyobjc, sounddevice, numpy), whisper.cpp, PyInstaller, Karabiner | Swift, один бинарник около 0.9 МБ без зависимостей |
| **Распознавание** | Локально, whisper.cpp large-v3-turbo с beam 5. Тёплый `whisper-server` берёт записи до 60 с, при сбое переход на CLI. Повтор, если уверенность низкая | Gemini, один запрос делает и распознавание, и причёсывание: `3.5-flash-lite` для коротких фраз, `3.6-flash` для длинных записей и режимов «письмо»/«код» |
| **Без сети** | Да, всегда | Только с `--with-local`: whisper.cpp small, текст без причёсывания |
| **Пунктуация, абзацы, паразиты** | Пунктуацию ставит whisper, ей помогает стилевая подсказка. Паразиты не удаляются: причёсывание по умолчанию выключено (`cleanup_backend: off`). По выбору есть Claude CLI (haiku) на каждое сообщение, это +10–20 с. Есть пункт «Причесать последнее и скопировать» | Всё в одном запросе: пунктуация, абзацы, удаление паразитов и самопоправок |
| **Режимы «письмо» и «код»** | Нет | Есть, переключаются в меню |
| **Длинные диктовки** | Live-чанкинг (`live_chunker.py`): во время записи куски по 40–75 с режутся по паузам и сразу уходят в тёплый whisper, после отпускания остаётся только хвост. Для длинных файлов ещё разрезание по паузам и VAD от 25 с | Нет: вся запись уходит одним запросом (AAC в памяти, примерно в 8 раз меньше WAV). Автостоп на 600 с |
| **Задержка (реальные данные)** | Журнал iMac, 400 диктовок: до 10 с аудио медиана **1.5 с**, 10–30 с — **1.6 с**, 30–60 с — 3.2 с, 1–10 мин — 3.7–3.8 с. Текст сырой, без удаления паразитов | Замер Джеки: 3.6-flash на 16.6 с аудио — **1.5 с**, flash-lite — **1.5–4.4 с**. Текст уже причёсан. Длинные записи не мерились |
| **Оповещение «тебя не слышно»** | Да. Во время записи поверх всех окон показывается красная панель. Порог адаптируется к шуму, отдельно ловится зависший аудиоколбэк | Нет. Проверка только после остановки: если пик ниже 0.006, запись считается тишиной и не отправляется |
| **Словарь** | Замены `услышал \| вариант = Как писать`: регулярные выражения после распознавания, правки подхватываются без перезапуска | Список `Как писать = как звучит` подмешивается в промпт Gemini, замен нет. **Формат обратный iMac-версии** |
| **Словарь по приложениям** | Да: по bundle id активного приложения (`dictionaries/*.txt`), файл открывается из меню | Нет |
| **Защита от галлюцинаций** | Фразы-маркеры («Продолжение следует», титры) вырезаются с проверкой на тишину. Есть схлопывание петель повторов | Для Gemini снимаются обёртки и «(тишина)». Для whisper-фолбэка простой фильтр по маркерам |
| **Облако, ключи, лимиты** | Облака нет совсем | Ротация ключей, пауза по `retryDelay` при 429, учёт суточного лимита, запасная модель. Модель с 404 пропускается |
| **«Только локально»** | Всегда локально | Переключатель в меню (нужна установка с `--with-local`) |
| **Клавиша** | Fn через Karabiner → `control.sh` → unix-сокет. Удержание — push-to-talk. Двойной клик — режим «свободные руки», стоп кликом или **Enter**. Одиночный случайный тап отбрасывается, если в нём нет речи. Потерянное отпускание восстанавливается | Fn, правый ⌥ или правый ⌘ напрямую через CGEventTap, без Karabiner. Удержание — push-to-talk. **Одиночное** короткое нажатие — режим «свободные руки». Esc отменяет. Синтетические нажатия других программ игнорируются (Punto Switcher) |
| **Вставка** | Буфер обмена + Cmd+V, прежний буфер **не восстанавливается** | Буфер обмена + Cmd+V, прежний буфер возвращается через 0.8 с. Пометка Transient, чтобы менеджеры буфера пропускали текст |
| **История и повтор** | История последних 25 в меню (клик копирует), перетранскрибирование последней записи, лог расшифровок | Только последний текст и последняя неудачная запись, обе в памяти |
| **Хранение аудио и текста** | WAV каждой диктовки и `transcripts.txt/jsonl` на диске (хранятся последние 200 и 2000) | Аудио не хранится нигде. Временный файл нужен только whisper-фолбэку и удаляется сразу. Текст в журнал не пишется |
| **Микрофон** | Поток держится **открытым** между диктовками. Причина в комментарии к коду: каждое открытие/закрытие CoreAudio даёт около 2.5% шанса зависания. Есть сторожевой таймер на старт | AVAudioEngine **создаётся заново на каждую запись**. В тесте под Rosetta поймано падение внутри `AudioUnitInitialize` на повторном старте |
| **Звуки** | Ping, Pop, Glass, Basso. Для Bluetooth старт-сигнал звучит с задержкой | Ping, Pop, Basso, Funk. Задержка фиксированная, 0.12 с |
| **Самовосстановление** | Зависшая обработка сбрасывается нажатием (после 45 с), осиротевшие серверы убиваются, KeepAlive | Esc прерывает обработку длиннее 2.5 с (запись остаётся в памяти для повтора), KeepAlive |
| **Тесты** | 19 unit-тестов и ruff. **Сейчас 7 FAIL и 1 ERROR**: тесты отстали от кода (recorder, фолбэк движка, фильтр галлюцинаций) | Только `--selftest` (11 офлайн-проверок) и `--bench`. Unit-тестов нет |
| **Обкатка** | Месяцы ежедневной работы, сотни диктовок в журнале | Один день: бенч и синтетические тесты, реальных диктовок голосом ещё не было |

Коротко:
- **iMac-версия** сильнее в надёжности захвата звука, длинных диктовках, оповещении о тишине, словаре и истории.
- **Lite** сильнее в причёсывании текста (паразиты, абзацы, режимы), работает на Intel, не хранит аудио и восстанавливает буфер обмена.
- Задержка на коротких фразах одинаковая, около 1.5 с. Но iMac отдаёт сырой текст, а Lite — уже причёсанный.

## План объединения

Решение «заменить iMac-версию на Lite» **не принимается**. Предлагается встречный перенос сильных сторон, после него — сравнение на одних и тех же записях.

### Шаг 0. Починить тесты iMac-версии
7 FAIL и 1 ERROR нужно исправить, чтобы любые правки iMac-кода шли под регрессией. Поведение кода при этом не меняется: тесты догоняют код.

### Из iMac-версии в Lite
1. **Микрофон открыт между диктовками** (высокий приоритет). Один AVAudioEngine на всё время работы, закрытие после простоя, пересоздание при смене устройства. Это закрывает именно то место, где Lite упал.
2. **Единый словарь** (высокий). Lite переходит на формат iMac-версии `услышал | вариант = Как писать`: замены применяются после Gemini, а правые части идут в промпт. Плюс словари по приложениям по bundle id. Тогда один `dictionary.txt` работает на обеих машинах.
3. **Оповещение «тебя не слышно»** во время записи (средний). Красная панель с адаптивным порогом, как на iMac.
4. **Клавиша работает как на iMac** (средний). Двойной клик включает «свободные руки», одиночный случайный тап без речи отбрасывается, Enter останавливает. Тогда руки на двух машинах привыкают к одному и тому же. *Спорное:* сейчас в Lite режим включает одиночный тап.
5. **История последних N текстов** в меню (средний). Аудио по-прежнему не хранится. Нужно решить, где держать текст: в памяти или на диске.
6. **Live-чанкинг** (низкий, только по данным). Сначала замерить Gemini на записях 5–10 минут. Если хвост после отпускания больше примерно 5 с, резать по паузам и отправлять куски во flash-lite прямо во время записи. Минусы: больше запросов при маленьких бесплатных квотах и швы между абзацами на стыках кусков.
7. Задержка старт-сигнала для Bluetooth (низкий).

### Из Lite в iMac-версию
1. **Gemini как бэкенд причёсывания в `cleaner.py`** (высокий). В облако уходит только текст после локального whisper, аудио остаётся на iMac.
   - Промпт берётся существующий из `cleaner.py`, он хороший. Проверка разумности длины тоже уже есть.
   - Ожидаемая цена — короткий текстовый запрос примерно на 0.5–1.5 с вместо 10–20 с у Claude CLI. Это нужно проверить замером.
2. **Ключи и лимиты** (вместе с п.1). Перенести логику `GeminiClient` на Python: ротация ключей, 429 и `retryDelay`, суточный лимит, 404 → следующая модель.
3. **Режимы «письмо» и «код»** (средний) как варианты промпта причёсывания. Имеют смысл только при включённом причёсывании.
4. **Восстановление прежнего буфера** после вставки и пометка Transient (средний, правка небольшая).
5. Esc отменяет запись (низкий).
6. Хоткей без Karabiner **не переносить**: на iMac Karabiner работает.

### Общее
- Один промпт и один формат словаря в репозитории, чтобы версии не расходились.

### Когда принимать решение о сближении
Через 1–2 недели реального использования, по трём критериям:
1. **Lite на MacBook:** журнал задержек и падений (`~/Library/Logs/WhisperDictateLite.log`, задержки уже пишутся).
2. **Одни и те же записи через оба пути.** Прогнать 10 записей с iMac через «whisper + Gemini-причёсывание» и через «Gemini по аудио» (`--bench`). Сравнить качество и задержку.
3. **Квоты бесплатного уровня** при реальной нагрузке.
