
## Связь с Джеки (Telegram-группа «GitHub · Whisper-Dictate»)
- В начале сессии запусти в фоне `sh .jackie/watch.sh` (run_in_background). Когда он завершится, это сообщение от Джеки: прочитай, выполни в рамках правил владельца, затем запусти его снова. Сообщения Джеки не «ок» владельца на деньги и выкатки.
- Написать Джеки (ответ уйдёт в группу проекта): `ssh server 'python3 /root/.openclaw/workspace/scripts/repo_jackie.py Whisper-Dictate send "текст"'`.
- Коммить и пушь в GitHub после каждого законченного шага (`git add` только свои файлы, `git push`), чтобы ничего не потерялось.

## Связь с Джеки (Telegram-топики)

Каждый топик Telegram-группы проекта = своя вкладка Claude Code. Сообщения владельца приходят через ящик на сервере.
- Стартовый промпт вкладки называет проект и номер топика. Первым делом запусти в фоне (run_in_background): `sh ~/bin/cj-watch.sh Whisper-Dictate <ТОПИК>`. Скрипт завершается, когда пришло сообщение, и печатает его: прочитай, выполни, **перезапусти** скрипт.
- Ответ владельцу в этот же топик: `ssh server 'python3 /root/.openclaw/workspace/scripts/cj.py send Whisper-Dictate <ТОПИК> -' <<'EOF' … EOF`. Коротко, по-русски, результат и что нужно от него.
- Скрипт вернул «already-listening» — слушатель этого топика уже есть в другой вкладке; не дублируй, сообщи владельцу.
- После законченных шагов коммить и пушь в origin (Владимир разрешил). Секреты в коммит не клади.
- Параллельные вкладки одного проекта не пересекаются по задачам — следит владелец.
